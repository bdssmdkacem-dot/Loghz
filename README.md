# لعبة الألغاز 🧩

مرحلة 1: الأساس (Splash + Home + Navigation + نموذج بيانات الألغاز). ✅
مرحلة 2: شاشة اللعب الفعلية (عرض اللغز، الاختيارات، التحقق من الجواب، النقط، الصوت). ✅
مرحلة 3: حفظ التقدم محليًا (أفضل نتيجة + عدد مرات اللعب عبر AsyncStorage). ✅
مرحلة 4: تحسينات بصرية (رسوم متحركة، شريط تقدم، أيقونات نوع اللغز). ✅
مرحلة 5: التحضير للنشر (أيقونة نهائية، splash نهائي، إعداد EAS Build). ✅
تحسين: بنك ألغاز حقيقي (18 لغز، صعوبات مختلفة) + ترتيب عشوائي فكل لعبة. ✅
تحسين: شاشة اختيار الصعوبة (الكل/سهل/متوسط/صعب) + نظام قلوب (3 محاولات). ✅
تحسين: اهتزاز (Haptics) عند الجواب الصحيح/الخاطئ ونهاية اللعبة. ✅
تحسين: صور حقيقية للحيوانات مع مجموعة موسعة من الأصول. ✅

## كيفاش تشغل المشروع

```bash
npm install
npm start
```

المشروع مبني بـ Expo / React Native، ويحتوي على Splash، Home، اختيار الصعوبة، اللعب، حفظ النتائج محلياً، Haptics، وصور حقيقية للحيوانات.
