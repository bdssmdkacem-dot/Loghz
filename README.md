# لعبة الألغاز 🧩

لعبة ألغاز بـ Expo/React Native، فيها ألغاز نصية وصورية وصوتية اختيارية، مع صعوبات مختلفة، قلوب، اهتزاز، وحفظ محلي للنتائج.

## الحالة الحالية

- بنك الألغاز الموجود في `src/data/riddles.js`: **21 لغزًا فعليًا** حسب الكود الحالي.
- منها **4 ألغاز صور حقيقية**: 🦁 أسد، 🦉 بومة، 🦊 ثعلب، 🐘 فيل.
- الصور موجودة في `assets/images/animals/` ومربوطة مباشرة في `GameScreen.js`.
- صورة اللغز أصبحت أكبر لسهولة رؤية الحيوان على الهاتف.
- `icon.png` ليست جزءًا من `imageMap`؛ تبقى فقط كأيقونة التطبيق في `app.json`.
- توجد ألغاز نصية، ولغز صوتي واحد، لكن ملف صوت الحيوان الحقيقي غير مرفق في المشروع حاليًا.

## الصور: ما تم فعله

الألغاز الصورية الأربعة تستخدم ملفات PNG حقيقية وليست placeholder:

- `lion.png`
- `owl.png`
- `fox.png`
- `elephant.png`

في `GameScreen.js` تم حذف أي اعتماد على أيقونة التطبيق كصورة للغز، واستعمال ملفات الحيوانات مباشرة. حجم العرض الحالي هو 280×280 حتى تكون الصورة واضحة.

## الصوت: محدودية صريحة

لم يتم اختلاق أو الادعاء بوجود تسجيلات حقيقية للحيوانات. لغز الصوت `r3` موجود، لكن `audioMap` يظل معلقًا إلى أن يضاف ملف صوت حقيقي.

بعد الحصول على تسجيل مجاني يسمح باستخدامه، ضع الملف هنا:

`assets/audio/riddle_sound_1.mp3`

ثم فعّل:

```js
const audioMap = {
  "riddle_sound_1.mp3": require("../../assets/audio/riddle_sound_1.mp3"),
};
```

يمكن البحث عن تسجيلات مرخصة للاستخدام في مصادر مثل Freesound أو Pixabay Sound Effects، مع التأكد من شروط الترخيص لكل ملف.

## التشغيل

1. Node.js 18 أو أحدث.
2. ثبّت الاعتمادات:
   ```
   npm install
   ```
3. شغّل:
   ```
   npm start
   ```
4. افتح المشروع عبر Expo Go.

## البناء

نسخة APK للتجربة:

```
eas build --platform android --profile preview
```

نسخة AAB للنشر:

```
eas build --platform android --profile production
```

قبل البناء النهائي، يجب استبدال `REPLACE_WITH_YOUR_EAS_PROJECT_ID` في `app.json` بمعرّف مشروع EAS حقيقي.

## المزايا الموجودة

- Splash مع animation.
- Home مع أفضل نتيجة وعدد مرات اللعب.
- اختيار مستوى الصعوبة.
- ترتيب عشوائي للألغاز.
- 3 قلوب للمحاولة.
- Haptics للإجابات الصحيحة والخاطئة ونهاية اللعبة.
- حفظ النتائج محليًا بواسطة AsyncStorage.
- ألغاز نصية وصورية.
- دعم لغز صوتي عندما يضاف ملف الصوت الحقيقي.

## ملاحظة
