# Loghz — ألغاز الحيوانات 🧩

لعبة ألغاز عربية مبنية باستخدام Expo وReact Native، مع اختيار مستوى الصعوبة، جولات أسئلة، احتساب النقاط والمحاولات، وحفظ التقدم محليًا.

## الحالة الحالية

- شاشة البداية والرئيسية واختيار الصعوبة وشاشة اللعب.
- بنك يضم 21 لغزًا حاليًا، بمستويات سهلة ومتوسطة وصعبة.
- رسوم حيوانات متجهية مخصصة داخل شاشة اللعب (أسد، بومة، ثعلب وفيل)، وليست صورًا فوتوغرافية.
- عرض نتيجة الإجابة مع تباين نصي واضح، ومؤثرات الاهتزاز عند توفر دعم الجهاز.
- توضيح داخل الواجهة عندما يكون الصوت غير متوفر؛ **ملفات الصوت الفعلية ما زالت تحتاج إلى الإضافة والتحقق**.
- فحص آلي لسلامة بيانات الألغاز ومراجع الأصول وإعداد Expo.

## التشغيل محليًا

يتطلب Node.js 20 أو إصدارًا متوافقًا مع Expo SDK 51.

```bash
npm install
npm run validate
npx expo config --type public
npx expo start
```

لتصدير حزمة JavaScript الخاصة بـ Android:

```bash
npx expo export --platform android --output-dir dist
```

## التحقق المستمر (CI)

يتحقق GitHub Actions من بيانات الألغاز ومراجع الأصول، ويفحص إعداد Expo، ثم ينفذ تصدير Android JavaScript. نجاح هذا المسار **ليس بديلًا** عن بناء APK/AAB أصلي أو اختبار الواجهة فعليًا على هاتف Android.

## قبل الإصدار التجاري

- إعداد أيقونة التطبيق النهائية وصورة Splash وأيقونة Android التكيفية، ثم اختبار ظهورها على الجهاز.
- إضافة ملفات صوت حقيقية مرخّصة والتحقق من تشغيلها، أو إزالة أسئلة الصوت إلى حين جاهزيتها.
- تثبيت التطبيق على هاتف Android واختبار الشاشات، أحجام النصوص، التنقل، حفظ التقدم، الاهتزاز والصوت.
- إنشاء وفحص بناء Android أصلي قبل اعتبار الإصدار جاهزًا للنشر.
